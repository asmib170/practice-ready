# Practice Ready

Practice Ready is an HCI/UI-UX prototype designed to improve Music Practice Room (MPR) booking and equipment readiness at the True School of Music.

The project helps students check whether a suitable practice room and the equipment they need are available before arriving for practice.

## Core Features

- View MPR availability in 30-minute intervals
- Reserve an MPR for a selected date and time
- View equipment assigned to each MPR
- Check equipment current locations and working conditions
- Search the equipment directory by name or ID
- Browse equipment by location
- View reference images for equipment identification
- Review equipment availability issues before booking
- Handle booking conflicts and recover by selecting another time or room

## Design Process

Practice Ready was developed through an HCI/UI-UX process involving user interviews, information architecture, card sorting, tree testing, skeletal wireframing, heuristic inspection, prototyping, and usability feedback.

The interface focuses on clear system status, error prevention, consistency, recognition rather than recall, user control, and responsive desktop and mobile layouts.

## Local Setup

Install dependencies:

    pnpm install

Build the project:

    pnpm build

## Project Status

Practice Ready is currently a functional interactive prototype developed for HCI/UI-UX evaluation and usability testing. Equipment and scheduling information used in the prototype is illustrative and should not be treated as an authoritative live inventory or booking system.
